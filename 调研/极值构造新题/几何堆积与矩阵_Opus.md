## 结论

推荐顺序：

1. **整数半径圆填圆**（半径 1…N，N=1000）：最值得继续做，但目前只有单种子探测。
2. **XOR 电路最小化**（n×n 随机 F2 矩阵）：曲线同样平稳，但没有公开纪录，也只有单种子探测。
3. **K_n 直线画法交叉数**（n=504）：这是唯一测满 5 个种子的题，结果**没有达标**，单次运行有双峰，只能有条件备选。

## 第 1 名：整数半径圆填圆

| 项 | 内容 |
|---|---|
| 定义 | 把半径分别为 1, 2, …, N 的 N 个圆放进一个大圆，圆之间不重叠，都在大圆内。取 N=1000，大圆半径 R 越小越好。 |
| 提交与判分 | 提交 R 和 N 行圆心坐标（有限位小数）。用整数精确检查每一对 (Δx²+Δy²≥(rᵢ+rⱼ)²) 和包含关系 (x²+y²≤(R−rᵢ)²)。文件约 30 KB。判分脚本已用 N=200 的解验证通过，密度与求解器一致。 |
| 已知最好值 | N=1000：R=19159.5928500688，密度 0.909405（我核算过 Σi²/R²，相符）。另有 N=300 密度 0.901751，N=2000 密度 0.911081，N=200 密度 0.901625。来源：[Packomania ccin 表](https://www.packomania.com/ccin/ccin.html)（2026-09-10 更新）、[Müller 的仓库](https://github.com/muellan/packing)。这也是 Al Zimmermann 竞赛的题集，方法见 [Müller 等 2009，模拟退火](https://link.aps.org/doi/10.1103/PhysRevE.79.021102)。 |
| 方法层级 | 见下表。 |
| 实验数据 | **只有 N=500 的单种子探测，没有 5 种子数据，也没有 300 秒数据。** N=1000 未实测。 |
| 初始方法影响 | 单种子下，随机起点到 28 秒已超过贪心起点，40 秒时为 0.8746 对 0.8725。同样从贪心起点出发，普通 ILS 几乎不动（25 秒 0.8512），换成 QP 就能继续涨，说明差距主要在方法，不在起点。 |
| 风险 | 没有闭式解可套，纪录表只有在线数据，作答时不能联网。曲线高段是否会变慢、14 线程跑 60 分钟能到哪里，都未实测。Packomania 说 N=300 等大规模纪录靠简单换圆还能略微改进，说明纪录并不紧（单一来源）。实现中等：需要带邻居表的 L-BFGS 和找空洞。**我的程序在 `qp int 100` 默认参数下出现过一次段错误，原因未查明**；N=200、N=500 正常。 |
| 建议锚点 | 密度→分：0.75→0，0.82→10，0.85→30，0.875→55，0.89→75，0.90→88，0.909405→100。高于 0.875 的部分是按斜率估计的，用前要用 N=1000 的实测校准。 |

## 第 2 名：XOR 电路最小化

| 项 | 内容 |
|---|---|
| 定义 | 给定 n×n 的 F2 矩阵 M（用 splitmix64 从固定种子生成，一句话能写清）。用最少的两输入 XOR 门，从 n 个输入算出 Mx 的全部 n 个输出。门数越少越好。建议 n=256。 |
| 提交与判分 | 提交门列表，每行两个信号编号，并指明每个输出是哪个信号。用位运算逐门算出线性函数，再和 M 精确比较。n=256 时约 1 万行。 |
| 已知最好值 | 没有这个实例的公开纪录，只能用自测基准。Lupanov 型渐近量级约 n²/log₂n（n=128 时约 2340，只是量级参考）。Paar、Boyar–Peralta 等方法名来自我的记忆，本次**没有核对来源**。 |
| 方法层级 | 见下表。 |

## 第 3 名（有条件）：K_n 直线画法交叉数

## 其他候选

**实测后淘汰：**

- **等圆填圆**（N=1000）：纯六角格切割就到比值 34.045（密度 0.8627），纪录是 33.942（0.8680），只差 0.3%。随机起点压缩 25 秒反而更差（34.48）。闭式构造直接拿到很高的位置，提升路程太短。其他规模的比值（六角格 / [纪录](https://www.packomania.com/cci/)）：N=200 为 15.737 / 15.463，N=500 为 24.322 / 24.131，N=800 为 30.597 / 30.418。
- **矩阵乘法张量秩**（F2）：阶梯式目标，一个秩就是一大截分数。
  - 实测：3×3×3 到 23（已验证）；4×4×4 约 5 秒到 52，之后到 240 秒都没动，停滞占比 0.94；5×5×5 在 40 秒内停在 125。都是单种子，程序也没有优化。
  - 文献：[GPU 论文](https://arxiv.org/pdf/2609.17533)在 H200 上跑 300 秒，从平凡解只到 47.6、108.2、205.5、335.3（4×4 到 7×7）；7×7 的 F2 纪录为 245。[5×5 为 93、6×6 为 153](https://arxiv.org/abs/2502.04514)。
  - 从平凡解出发很慢，强起点又靠块分解组合，符合这次要淘汰的“长时间不动再跳变”。

**未实测，只是推理：**

| 题目 | 不优先的原因 |
|---|---|
| 最大行列式（±1 矩阵） | Paley 等闭式起点很强，局部搜索估计难以从随机起点追上；纪录见 [Orrick 等](https://arxiv.org/abs/math/0304410)，其方法未细读 |
| Thomson 问题 / 球面 Tammes | 目标平滑，但基础优化器可能很快收敛到窄带，提升路程可能短；Thomson 还要处理无理数判分 |
| 星差异（2D，N≈1000） | 有闭式低差异点集作起点；[定制排列的方法](https://arxiv.org/abs/2407.11533)比 MPMC 点集平均再低约 20%（来自讲座摘要）；是瓶颈型目标，值得以后再看 |
| 接吻数构造 | 强解依赖结构化编码，容易变成背构造 |
| 面积最优多边形化（[CG:SHOP 2019](https://arxiv.org/abs/2111.07304)） | 目标平滑、实例可生成，但维护简单多边形的实现成本高 |
| 球填球 | 计算量更大，纪录覆盖情况没有查 |

## 排名理由和定题前要补的测量

**为什么前两名可能比 LABS 合适：** 它们的目标由大量局部贡献累积而成，一次改动只带来小幅变化，好解多而连续。单种子曲线每次加倍都在涨，没有 LABS 那种长时间停滞后的跳变。这个判断还缺多种子数据支持。

**定题前至少补测（机器空闲时）：**

1. 圆填圆 N=1000：随机、贪心、ILS、QP 各 5 个种子，300 秒；QP 再跑 600 秒，看均值和波动；续跑一到两轮，看高段曲线。
2. XOR n=128 和 n=256：Paar 和迭代贪心各 5 个种子，300 秒和 600 秒；差起点 300 秒，看能否追上。
3. 交叉数：每个方法 8 个种子取最好，重复几轮，看双峰是否真被消掉；再用差峰的解试能否追上。
4. LABS：提速版斜对称（13.5M 次/秒，已通过增量能量校验）跑 8 个种子，600 秒，把对照拉到锚点陡升段。
5. 查明 `pack` 的段错误。用 `*2.exe`（按 CPU 时间计预算）；若仍有负载竞争，把各种子的计算量一起记录。
