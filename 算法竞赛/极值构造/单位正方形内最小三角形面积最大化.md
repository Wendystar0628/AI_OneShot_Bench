# 题目

本题是一道极值构造题：给出一个让目标值尽可能好的构造。采用什么构造或搜索策略，由你自己决定。

从普通水平到较好水平，同样的进步在计分中的分量逐段加大；逼近已知最好结果的最后一段不额外加权。请尽可能做出更好的结果。作答过程中，如果某个方向的方案难以继续推进，可以考虑换一个思路。

取 $n=30$，记单位正方形为 $U=[0,1]^2$。对平面上的点 $p=(x_p,y_p)$、$q=(x_q,y_q)$、$r=(x_r,y_r)$，三角形 $pqr$ 的面积为

$$
A(p,q,r)=\frac12\left|(x_q-x_p)(y_r-y_p)-(x_r-x_p)(y_q-y_p)\right|.
$$

对 $n$ 个点 $p_1,p_2,\ldots,p_n\in U$，定义

$$
\Delta(p_1,\ldots,p_n)=\min_{1\le i<j<k\le n}A(p_i,p_j,p_k).
$$

求 $p_1,p_2,\ldots,p_n\in U$，使 $\Delta(p_1,\ldots,p_n)$ 最大。

## 提交格式

在开始作答时所在的工作目录下，提交 `answer.md`，共 $n$ 行。文件只包含下面规定的内容，不加标题、代码块等 Markdown 标记。

- 第 $k$ 行写点 $p_k$ 的坐标 `x y`：两个数之间恰好一个空格，行首、行尾都没有空白；文件中不得有空行。
- 每个数写成 `0` 或 `1`，或者写成 `0.`、`1.` 后接 1 至 20 位数字（例如 `0.5`、`0.123456789`、`1.000`）。不带正负号，不使用科学计数法。
- 换行可以是 `\n` 或 `\r\n`，最后一行末尾的换行可有可无；文件开头允许有 UTF-8 BOM。

## 评价

- 评分对提交格式很宽容，格式上的小出入不用担心；但评测必需的内容仍按题面：文件中恰好有 $n$ 个点，每个点都在 $U$ 内。
- 按所写坐标精确计算 $\Delta$，越大越好。是否在 $U$ 内，同样按所写的十进制值精确判断。
- 点可以重合或共线，此时 $\Delta=0$，提交仍然有效。

## 注意事项

1. 使用 nvcc 前，需要先执行 `C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\VC\Auxiliary\Build\vcvars64.bat` 进入 MSVC 的 x64 开发环境。本机系统代码页为 936（简体中文），编译时加上 `-Xcompiler /utf-8` 可以避免 CUDA 头文件触发大量 C4819 警告。
2. 单个 GPU 内核执行超过约 2 秒，会触发 Windows 的 GPU 超时检测与恢复（TDR）：显卡驱动被重置，程序运行失败。
3. 部分命令行环境设置了环境变量 `NoDefaultCurrentDirectoryInExePath`，此时 `cmd` 不会在当前目录中查找可执行文件。运行当前目录下的程序时，请写成 `.\程序名.exe`。
