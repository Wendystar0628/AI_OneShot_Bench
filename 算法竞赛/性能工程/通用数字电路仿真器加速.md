# 题目

本题是一道性能优化工程题：在结果正确的前提下，让你的程序尽可能快。采用什么优化策略、怎样实现，由你自己决定。

越接近性能极限，同样的提速在计分中的分量越大。请尽可能做出更好的结果。作答过程中，如果某个方向的方案难以继续推进，可以考虑换一个思路。

## 一、问题

给定一个同步时序电路，由逻辑门和触发器组成。所有信号都是 1 位（取值 0 或 1），按下面的方式统一编号：

| 编号 | 含义 |
|---|---|
| $0$ | 常量 0 |
| $1$ | 常量 1 |
| $2,\ldots,I+1$ | 主输入 $\mathrm{PI}_0,\ldots,\mathrm{PI}_{I-1}$ |
| $I+2,\ldots,I+F+1$ | 触发器 $\mathrm{FF}_0,\ldots,\mathrm{FF}_{F-1}$ 的当前状态 |
| $I+F+2,\ldots,I+F+G+1$ | 逻辑门 $g_0,\ldots,g_{G-1}$ 的输出 |

**逻辑门**：每个门有一种类型和若干输入信号，输出按下表计算（$a,b,s$ 为输入信号的值）：

| 类型 | 输入个数 | 输出 |
|---|---|---|
| `AND` | 2 | $a\wedge b$ |
| `OR` | 2 | $a\vee b$ |
| `XOR` | 2 | $a\oplus b$ |
| `NAND` | 2 | $\neg(a\wedge b)$ |
| `NOR` | 2 | $\neg(a\vee b)$ |
| `XNOR` | 2 | $\neg(a\oplus b)$ |
| `NOT` | 1 | $\neg a$ |
| `MUX` | 3（依次为 $s,a,b$） | $s=0$ 时为 $a$，$s=1$ 时为 $b$ |

门的输入可以是任意编号的信号；同一个信号可以被多个门使用，一个门的多个输入也可以是同一个信号。保证门与门之间的依赖关系没有环。门不一定按依赖顺序给出。

**触发器**：每个触发器 $\mathrm{FF}_f$ 有一个数据输入信号 $d_f$，可以是任意编号的信号。

**主输出**：给定 $O$ 个信号编号 $o_0,\ldots,o_{O-1}$，可以是任意编号的信号。

**仿真过程**：对 $M$ 组互相独立的激励 $m=0,1,\ldots,M-1$ 分别仿真。每组开始时，所有触发器状态为 0，然后依次运行 $T$ 个周期 $t=0,1,\ldots,T-1$。每个周期按顺序执行：

1. 主输入取值：$\mathrm{PI}_i$ 取 $r_{m,t}$ 的第 $i$ 位（最低位为第 0 位），$r_{m,t}$ 的定义见第二节。
2. 根据主输入和触发器的当前状态，计算所有逻辑门的输出。
3. 记录 $O$ 个主输出的值。
4. 所有触发器同时更新：$\mathrm{FF}_f\leftarrow$ 信号 $d_f$ 在本周期的值。若 $d_f$ 指向另一个触发器，读取的是它更新前的状态。

**输出摘要**：记 $v_{m,t,j}$ 为第 $m$ 组激励在第 $t$ 个周期中主输出 $o_j$ 的值，定义

$$
H_m=\bigoplus_{\substack{0\le t<T,\ 0\le j<O\\ v_{m,t,j}=1}}\operatorname{mix64}(t\cdot O+j),
$$

其中 $\bigoplus$ 表示按位异或，没有满足条件的项时 $H_m=0$。

**任务**：对每组激励求出 $H_m$。

## 二、伪随机数与摘要函数

所有运算都是 64 位无符号整数运算（溢出时按模 $2^{64}$ 回绕）。

```c
uint64_t splitmix64_next(uint64_t *s) {
    uint64_t z = (*s += 0x9E3779B97F4A7C15ULL);
    z = (z ^ (z >> 30)) * 0xBF58476D1CE4E5B9ULL;
    z = (z ^ (z >> 27)) * 0x94D049BB133111EBULL;
    return z ^ (z >> 31);
}

uint64_t mix64(uint64_t x) {
    return splitmix64_next(&x);
}
```

第 $m$ 组激励的随机数状态初始化为 $s_m=\operatorname{mix64}(\mathit{seed}\oplus m)$。之后对 $t=0,1,\ldots,T-1$ 依次调用 `splitmix64_next(&s_m)`，第 $t$ 次调用的返回值就是 $r_{m,t}$。

## 三、测试文件格式

每个测试输入是一个文本文件，由评测程序读取并解析，解法不需要自己读文件。格式如下：

- 第一行七个整数 $I\ F\ G\ O\ M\ T\ \mathit{seed}$，其中 $\mathit{seed}$ 为 64 位无符号整数。
- 第二行 $F$ 个整数 $d_0,\ldots,d_{F-1}$。
- 接下来 $G$ 行，第 $k$ 行描述门 $g_k$：先是类型名，然后是它的输入信号编号（`NOT` 1 个，`MUX` 3 个，其余 2 个）。
- 最后一行 $O$ 个整数 $o_0,\ldots,o_{O-1}$。

## 四、函数接口

提交的 `solution.cpp` 中实现下面的函数。结构体 `Circuit` 的定义必须与评测程序中的完全一致：

```cpp
#include <cstdint>
#include <vector>

struct Circuit {
    int I, F, G, O, M, T;
    uint64_t seed;
    std::vector<int> d;
    std::vector<uint8_t> type;
    std::vector<int> in0, in1, in2;
    std::vector<int> out;
};

std::vector<uint64_t> simulate(const Circuit& c);
```

- `d` 有 $F$ 个元素，`d[f]` 即 $d_f$；`out` 有 $O$ 个元素，`out[j]` 即 $o_j$。
- `type`、`in0`、`in1`、`in2` 各有 $G$ 个元素，描述门 $g_k$。`type[k]` 的取值：0 `AND`，1 `OR`，2 `XOR`，3 `NAND`，4 `NOR`，5 `XNOR`，6 `NOT`，7 `MUX`。
- 输入信号编号按测试文件中的顺序依次放在 `in0`、`in1`、`in2` 中，用不到的为 $-1$。对 `MUX`，`in0`、`in1`、`in2` 依次为 $s,a,b$。
- 返回值有 $M$ 个元素，第 $m$ 个元素为 $H_m$。

## 五、评测程序

评测程序 `grader.cpp` 如下。它读取并解析测试文件，调用 `simulate()`，把结果按每行一个 16 位小写十六进制数写到标准输出，并把计时写到标准错误。

```cpp
// grader.cpp
// Usage: grader.exe <input file>
//   stdout: the M digests, one 16-digit lowercase hex number per line
//   stderr: "simulate_ms=<milliseconds>", the wall time of the timed simulate() call
#include <chrono>
#include <cstdint>
#include <cstdio>
#include <cstdlib>
#include <cstring>
#include <vector>
#ifdef _WIN32
#include <fcntl.h>
#include <io.h>
#endif

struct Circuit {
    int I, F, G, O, M, T;
    uint64_t seed;
    std::vector<int> d;              // size F: data input of each flip-flop
    std::vector<uint8_t> type;       // size G: 0 AND, 1 OR, 2 XOR, 3 NAND, 4 NOR, 5 XNOR, 6 NOT, 7 MUX
    std::vector<int> in0, in1, in2;  // size G: input signals; unused inputs are -1; MUX: in0=s, in1=a, in2=b
    std::vector<int> out;            // size O: primary outputs
};

std::vector<uint64_t> simulate(const Circuit& c);

static void fail(const char* msg) {
    fprintf(stderr, "grader: %s\n", msg);
    exit(1);
}

static Circuit parse(const char* path) {
    FILE* f = fopen(path, "rb");
    if (!f) fail("cannot open input file");
    std::vector<char> buf;
    char tmp[1 << 16];
    size_t got;
    while ((got = fread(tmp, 1, sizeof tmp, f)) > 0) buf.insert(buf.end(), tmp, tmp + got);
    fclose(f);
    buf.push_back(0);
    size_t p = 0;
    auto skip = [&] { while (buf[p] && (unsigned char)buf[p] <= ' ') p++; };
    auto num = [&]() -> uint64_t {
        skip();
        if (buf[p] < '0' || buf[p] > '9') fail("number expected");
        uint64_t x = 0;
        while (buf[p] >= '0' && buf[p] <= '9') x = x * 10 + (uint64_t)(buf[p++] - '0');
        return x;
    };
    static const char* names[] = {"AND", "OR", "XOR", "NAND", "NOR", "XNOR", "NOT", "MUX"};
    auto word = [&]() -> int {
        skip();
        size_t e = p;
        while ((unsigned char)buf[e] > ' ') e++;
        for (int t = 0; t < 8; t++)
            if (strlen(names[t]) == e - p && !strncmp(&buf[p], names[t], e - p)) { p = e; return t; }
        fail("unknown gate type");
        return -1;
    };
    Circuit c;
    c.I = (int)num(); c.F = (int)num(); c.G = (int)num(); c.O = (int)num(); c.M = (int)num(); c.T = (int)num();
    c.seed = num();
    c.d.resize(c.F);
    for (auto& x : c.d) x = (int)num();
    c.type.resize(c.G); c.in0.assign(c.G, -1); c.in1.assign(c.G, -1); c.in2.assign(c.G, -1);
    for (int k = 0; k < c.G; k++) {
        int t = word();
        c.type[k] = (uint8_t)t;
        c.in0[k] = (int)num();
        if (t != 6) c.in1[k] = (int)num();
        if (t == 7) c.in2[k] = (int)num();
    }
    c.out.resize(c.O);
    for (auto& x : c.out) x = (int)num();
    return c;
}

static Circuit sampleCircuit() {  // the sample from the problem statement
    Circuit c;
    c.I = 64; c.F = 2; c.G = 6; c.O = 3; c.M = 2; c.T = 4; c.seed = 12345;
    c.d = {68, 72};
    c.type = {2, 0, 1, 6, 7, 3};
    c.in0 = {70, 2, 69, 67, 5, 72};
    c.in1 = {66, 3, 4, -1, 71, 1};
    c.in2 = {-1, -1, -1, -1, 68, -1};
    c.out = {68, 72, 73};
    return c;
}

int main(int argc, char** argv) {
#ifdef _WIN32
    _setmode(_fileno(stdout), _O_BINARY);
#endif
    if (argc != 2) fail("usage: grader.exe <input file>");
    // Untimed warm-up on the sample circuit.
    std::vector<uint64_t> s = simulate(sampleCircuit());
    if (s.size() != 2 || s[0] != 0x90b37d5a4e5580f7ULL || s[1] != 0x8cdc0aaf7feb37edULL)
        fail("wrong result on the sample circuit");
    Circuit c = parse(argv[1]);  // untimed
    auto t0 = std::chrono::steady_clock::now();
    std::vector<uint64_t> h = simulate(c);
    auto t1 = std::chrono::steady_clock::now();
    if ((int)h.size() != c.M) fail("simulate() returned a wrong number of digests");
    std::vector<char> outbuf((size_t)c.M * 17);
    static const char hx[] = "0123456789abcdef";
    for (int m = 0; m < c.M; m++) {
        char* q = &outbuf[(size_t)m * 17];
        for (int i = 0; i < 16; i++) q[i] = hx[(h[m] >> (60 - 4 * i)) & 15];
        q[16] = '\n';
    }
    fwrite(outbuf.data(), 1, outbuf.size(), stdout);
    fprintf(stderr, "simulate_ms=%.3f\n", std::chrono::duration<double, std::milli>(t1 - t0).count());
    return 0;
}
```

## 十三、评分标准

评分对提交格式很宽容，格式上的小出入不用担心；但评测必需的内容仍按题面：`solution.cpp` 能用第八节的命令与评测程序一起编译，`simulate()` 的接口和 `Circuit` 的定义与第四节完全一致，并遵守第十节的规则。

满分 100 分。24 个性能输入各自单独计分，本题得分为 24 个输入得分的平均值。

设性能输入 $i$（$i=1,\dots,24$）上基线与提交的计时分别为 $R_i$、$C_i$，加速比 $s_i=R_i/C_i$。输入 $i$ 的得分按 $s_i$ 在对数尺度上分段插值，锚点如下：

| $s_i$ | 0.1 | 0.5 | 1 | 1.75 | 2.75 | 4 |
|---|---|---|---|---|---|---|
| 得分 | 0 | 10 | 30 | 52 | 75 | 100 |

$s_i\le0.1$ 时该输入得 0 分，$s_i\ge4$ 时得 100 分。$s_i$ 位于相邻锚点 $a_k\le s_i\le a_{k+1}$ 之间、两锚点的得分为 $p_k$、$p_{k+1}$ 时：

$$
\text{得分}_i=p_k+(p_{k+1}-p_k)\,\frac{\ln(s_i/a_k)}{\ln(a_{k+1}/a_k)}
$$

$$
\text{本题得分}=\frac{k}{7}\cdot\frac{1}{24}\sum_{i=1}^{24}\text{得分}_i
$$

其中 $k$ 为通过的正确性输入个数（0–7）。

各输入得分和本题得分都保留一位小数。越接近高加速比，同样的提速得分越多。
