## 第 1 题

$$
(b-a)\int_a^b|q(x)|\,\mathrm{d}x>4.
$$

    4 < (b - a) * ∫ x in a..b, |q x| := by

## 第 2 题

设 $p$ 是奇素数，$\mathbb{F}_p$ 是 $p$ 元域，函数 $f\colon\mathbb{F}_p\to\mathbb{F}_p$ 不能写成 $f(x)=ax+b$（$a,b\in\mathbb{F}_p$）的形式。对 $m\in\mathbb{F}_p$，若存在 $x\ne y$ 使 $f(x)-f(y)=m(x-y)$，就称 $m$ 是 $f$ 的图像确定的一个方向。证明：这样的方向至少有 $\dfrac{p+3}{2}$ 个。

```lean
theorem problem2 (p : ℕ) [Fact p.Prime] (hp : 2 < p)
    (f : ZMod p → ZMod p)
    (hf : ¬ ∃ a b : ZMod p, ∀ x, f x = a * x + b) :
    p + 3 ≤ 2 * Set.ncard {m : ZMod p |
      ∃ x y : ZMod p, x ≠ y ∧ f x - f y = m * (x - y)} := by
  sorry
```

## 第 3 题

设 $\mathcal A$ 是由有限集组成的非空有限集族，并且对并运算封闭（$a,b\in\mathcal A$ 时 $a\cup b\in\mathcal A$）。证明：

$$
|\mathcal A|^{|\mathcal A|}\le 2^{2\sum_{a\in\mathcal A}|a|},
$$

也就是 $\mathcal A$ 中集合的平均大小至少为 $\frac12\log_2|\mathcal A|$。

```lean
theorem problem3 {α : Type*} [DecidableEq α]
    (A : Finset (Finset α)) (hA : A.Nonempty)
    (hunion : ∀ a ∈ A, ∀ b ∈ A, a ∪ b ∈ A) :
    A.card ^ A.card ≤ 2 ^ (2 * ∑ a ∈ A, a.card) := by
  sorry
```

## 第 4 题

设自然数 $r\le n$，$S$ 是 $n$ 阶复矩阵空间的复线性子空间，其中每个矩阵的秩都不超过 $r$。把 $n$ 阶复矩阵 $A$ 看成 $\mathbb{C}^n$ 上的线性映射 $x\mapsto Ax$。证明：$\dim S\le nr$；并且当 $\dim S=nr$ 时，或者存在 $\mathbb{C}^n$ 的 $r$ 维子空间 $U$，包含 $S$ 中所有矩阵的像，或者存在 $\mathbb{C}^n$ 的 $n-r$ 维子空间 $W$，含于 $S$ 中所有矩阵的核。

```lean
theorem problem4 (n r : ℕ) (hr : r ≤ n)
    (S : Submodule ℂ (Matrix (Fin n) (Fin n) ℂ))
    (hS : ∀ A ∈ S, A.rank ≤ r) :
    Module.finrank ℂ S ≤ n * r ∧ (Module.finrank ℂ S = n * r →
      (∃ U : Submodule ℂ (Fin n → ℂ), Module.finrank ℂ U = r ∧
        ∀ A ∈ S, LinearMap.range A.mulVecLin ≤ U) ∨
      (∃ W : Submodule ℂ (Fin n → ℂ), Module.finrank ℂ W = n - r ∧
        ∀ A ∈ S, W ≤ LinearMap.ker A.mulVecLin)) := by
  sorry
```

## 作答格式与要求

1. 每题一个文件：在开始作答时所在的工作目录下，第 k 题写入 `Problemk.lean`，即 `Problem1.lean` 到 `Problem5.lean`。
