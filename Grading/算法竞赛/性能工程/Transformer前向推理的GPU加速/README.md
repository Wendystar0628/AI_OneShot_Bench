# Transformer前向推理的GPU加速：隐藏测试数据

本目录是题目《Transformer前向推理的GPU加速》的隐藏测试数据和出题工具，**不能让被测模型接触**。

## 目录内容

| 路径 | 说明 |
|---|---|
| `performance/inputs/input_01.bin` – `input_24.bin` | 24 个隐藏性能输入：8 类参数配比，每类 3 个实例 |
| `performance/expected/expected_01.bin` – `expected_24.bin` | 对应的标准答案（FP32 原始数据），由 FP64 求解器算出 |
| `correctness/inputs/`、`correctness/expected/` | 7 个小规模正确性输入及答案，每个占本题得分的 1/7 |
| `generator/gen_hidden.cpp` | 输入生成器和 FP64 求解器 |
| `grader/grader.cu` | 官方评测程序，与题面第四节中的代码一致 |
| `baselines/reference_solution.cu` | 基线：FP32，共享内存分块，注意力融合在线 softmax，不用张量核心。每次评测重新运行，其用时 $R_i$ 是加速比的分母 |
| `validation.json` | 每个性能输入所属的类别，`evaluate.py` 报告用 |

`.bin` 共约 9 GiB，不进 git。在本目录用下面的命令重建，约 20 分钟，主要占 CPU：

```powershell
g++ -O3 -march=native -fopenmp -std=c++17 -static -o C:\eval\transformer\gen_hidden.exe generator\gen_hidden.cpp
C:\eval\transformer\gen_hidden.exe
```
