# 通用数字电路仿真器加速：隐藏测试数据

本目录是题目《通用数字电路仿真器加速》的隐藏测试数据和出题工具，**不能让被测模型接触**。

## 目录内容

| 路径 | 说明 |
|---|---|
| `performance/inputs/input_01.txt` – `input_24.txt` | 24 个隐藏性能输入，每个约 9 MB：8 类电路结构，每类 3 个实例 |
| `performance/expected/expected_01.txt` – `expected_24.txt` | 对应的标准答案（评测程序的标准输出），由基线算出 |
| `generator/gen_hidden.cpp` | 隐藏输入生成器 |
| `grader/grader.cpp` | 官方评测程序，与题面第五节中的代码逐字节一致 |
| `baselines/reference_solution.cpp` | 基线：出题人写的通用优化解法，每次评测重新运行，其用时 $R_i$ 是加速比的分母 |
| `correctness/inputs/`、`correctness/expected/` | 7 个正确性输入及独立参考答案，每个占本题得分的 1/7，失败一个就去掉那一份 |
| `validation.json` | 每个性能输入所属的类别，`evaluate.py` 报告用 |

所有文件都使用 LF 换行。

各类结构与参数含义（生成器第 3 个及之后的参数；省略时取方括号中的默认值，与上一版输出逐字节相同）：

- **深链**：每个门的输入大多来自最近生成的若干个门，依赖链极长。参数为取输入的窗口大小 [64]；窗口越小，链越深。
- **多层宽网格**：输入主要来自上一层，另有约 20% 跨层长距离连线。参数为层数 [40]，主体约 45 万个门平均分到各层。
- **阵列乘法器**：大量阵列乘法器，部分乘积再经加法器累加。参数为乘数位宽 [16]。
- **分组密码轮函数**：64 位状态经异或轮密钥、4 位非线性替换、置换和线性混合。参数为每块的最少轮数 [6]，每块轮数在该值到该值加 6 之间随机。
- **控制逻辑**：多路选择树、16 位比较器、相等判断和译码器。参数为选择位数 [5]，即 $2^k$ 选 1 和 $k$–$2^k$ 译码。
- **寄存器堆**：4096 个触发器组成 $2^a$ 个 $4096/2^a$ 位寄存器，64 个读口，外加胶合逻辑。参数为地址位数 $a$ [7] 和写口数 [16]。
- **环形流水线**：每级读上一级的寄存器、写本级的寄存器，最后一级接回第一级。参数为级数 [16]，每级写 $\min(448,\ 8192/\text{级数})$ 个触发器。
- **混合 SoC**：乘法器、密码轮、控制逻辑和随机逻辑块混合。三个参数为乘法器、密码轮、控制逻辑块的累计百分比 [25 50 70]，其余为随机逻辑块。

所有电路都满足：每个门在结构上均可到达某个触发器或主输出，每个触发器都经异或折叠接到主输出。这不等于经过布尔化简后每个门都不可删除。

## 正确性输入

| 用例 | 覆盖内容 |
|---|---|
| `01_ff_forward` | 触发器按正向编号直接依赖，检查同时更新 |
| `02_ff_reverse` | 反向编号的触发器依赖，检查反向原地更新 |
| `03_direct_sources` | 常量、主输入、触发器的直接连接与直接输出、自反馈、无关门 |
| `04_shuffled_dag` | 八种门、重复输入、乱序 DAG、小规模组合与时序混合 |
| `05_shuffled_dag` | 257 组激励，覆盖向量批次与尾部处理 |
| `06_shuffled_dag` | 另一组固定随机 DAG 与不同周期数 |
| `07_fullsize_ff_snapshot` | 与性能输入同规模的双向触发器延迟链，检查大规模路径的同时更新 |

前六例由逐激励、逐周期的 Python 标量仿真器生成答案；第七例的门均为不被观察的 `NOT(0)`，输出只观察四个触发器和常量，由独立推导的周期波形计算摘要。全部可用上一级 `gen_correctness.py --task circuit` 重建。

## 基线

- **基线**：只保留能影响输出的门；在深度优先序和按层序中选需要存储位置更少的一种，并复用已不再使用的存储位置；软件预取；AVX2 一次处理 256 组激励；门计算无分支；用 64×64 位矩阵转置生成主输入、计算摘要。
- 提交在某个输入上的 $s_i\le0.1$（不到基线速度的十分之一）时，该输入得 0 分；题面第十节另规定每次运行的整个进程不超过 60 秒，`evaluate.py` 对超过 60 秒的运行判为失败。

## 评测时

在本目录的上一级运行统一工具，基线可执行文件必需：

```powershell
python evaluate.py --task circuit --exe C:\eval\circuit\grader.exe --reference C:\eval\circuit\reference.exe --report C:\eval\circuit-result.json
```

工具先运行提交的 7 个正确性输入（失败一个，本题得分去掉 1/7，后面照常运行）；再在每个性能输入上让基线和提交各运行 3 次（奇数输入先基线后提交，偶数输入先提交后基线，取各自中位数），按题面评分标准输出 $R_i$、$C_i$、$s_i$、各输入得分、作参考的 $G$ 和本题得分。基线本身运行失败时这次评测作废。具体说明见上一级 README。

由生成参数重新生成输入：

```
g++ -O2 -std=c++20 -march=native -o gen_hidden.exe gen_hidden.cpp
gen_hidden.exe deep 6151827736420917 > input_01.txt
gen_hidden.exe regfile 5872924447304816 8 24 > input_18.txt
```
