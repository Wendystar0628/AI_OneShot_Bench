# Grading：评分资料

本目录是题集 `AI_OneShot_Bench` 的评分部分，存放评分需要的全部资料：标准答案、隐藏测试数据、基线、评测脚本和各题的 AI 评分指南。受测模型作答期间不能接触本目录：给受测模型复制题面时不要带上本目录，也不要把它的路径告诉受测模型。

## 目录结构

目录与题集一一对应，题集中的每道题在这里都有一个同名文件夹，里面都有一份 `AI评分指南.md`；标准评判题只有 `评分表_6.1Sol.md`，主动设计题另有 `评分表_Opus5.5.md`（下面的目录树中省略）。

## 题目文件夹里的文件

| 文件 | 内容 |
|---|---|
| `AI评分指南.md` | 评分要点（在题面评分标准的基础上稍作扩充）、要看的材料、输出的内容 |
| `评分表_Opus5.5.md`、`评分表_6.1Sol.md` | 按题型配置的空白评分表（标准评判题只用 Sol，设计题主体用两位），记录分项得分：列出各分项的评分要点和本题的计分公式，留出得分、总分和一段 50 字左右的简评（锐评，不端水，一针见血地指出本题结果中最有说明价值的内容）。分项理由写在评分结果里。评分开始时复制到受测模型的作答目录，由评分员填写 |
| `参考答案.md` | 两道证明题的出处与解答：形式化证明题附纸面证明思路，完整的 Lean 参考证明在 `参考证明/`；IMO原创新题附标准解答和每题的 7 分评分要点 |
| `check_answer.py` | 极值构造题的格式校验与精确计算 |

性能题另有隐藏输入、标准答案、基线和输入生成器，说明见 `算法竞赛/性能工程/README.md` 和各题目录下的 `README.md`。

## 评分分工

- 评分 AI 是 Claude Opus 5.5 和 GPT 6.1 Sol，从管理员账户的 Claude Code 和 Codex 发起，用管理员账户自己的登录；不是从受测模型运行所用的普通账户发起，那个账户读不到本目录。推理强度：评 IMO原创新题和形式化证明题用 `xhigh`，其余（含设计题、极值构造和全部性能部分）用 `high`。
- 评分 AI 按各题的 `AI评分指南.md` 打分，主观部分由它自行判断，分数可以打小数（保留一位小数）；评分时能看到模型代号。
- 评分时打开网页、测试交互功能，一律用本机的无窗口（headless）Chrome，禁止占用出题人的电脑桌面：不开有窗口的浏览器等桌面程序，不用控制或截取桌面的工具。
- 评分员的具体步骤和可用工具（Chrome 的启动参数与驱动方式、本地网页服务器、系统读数、ffmpeg、Lean、各题脚本）写在评分员提示词 `orchestrator\grader-prompt.txt` 里，每次评分随任务下发。
- 五道主动设计题主体由 Claude Opus 5.5 和 GPT 6.1 Sol 独立评分；深度推理、算法竞赛六道标准评判题整题及所有性能部分只由 Sol 评分。评分 AI 只给出本人负责的一份。
- 共 16 对题目与评分员、17 个会话。主体共 14 个会话并行评分（设计题 5×2，加形式化、IMO、两道极值构造各 1 个 Sol 会话）；全部结束后，性能共 3 个 Sol 会话按题目表顺序独占机器串行评分：AE 的“性能”与主体分段，合并后由程序从分项加总；Transformer、电路整题排入性能队列，得分由 `evaluate.py` 按题面公式计算。物理整题 8 个方向、29 个分项由两位评分员各一次评完。
- 极值构造题按指南里的公式，以已知最好的构造值为 100 分换算。
- 题面“规定”一节的执行情况不在评分范围内，由出题人处理。

## 计分与总分

- 每道题都折算为 0–100 分：原始分 ÷ 满分 × 100。例如IMO原创新题满分 84（12 题各 7 分），按 ×100/84 折算；其余各题满分都是 100。
- 标准评判题直接采用 Sol 的折算分。设计题主体分项取有效评分员的平均，只有一位有效时用该位；性能分项只用 GPT 6.1 Sol。合成分 = 主体分项平均之和 + Sol 性能分，再折算为 0–100 分。设计题各分项由评分员在分值内直接打分，相加为总分，不扣分。
- 偶发故障按段最多重试一次；设计题主体一位失败时依另一位。单评分员的段重试仍失败，该段没有分数，列入“评分失败”缺口；缺少必需段的题没有本题得分，不按剩余分项放大，模型汇总暂按 0 分计。
- 模型总分是各题得分的加权平均，各题权重如下：

| 类别 | 类别权重 | 题目与权重 |
|---|---|---|
| 深度推理 | 17.5% | 形式化证明题 8.75%，IMO原创新题 8.75% |
| 算法竞赛 | 17.5% | 两道极值构造题、两道性能题，各 4.375% |
| 复杂交互应用 | 15% | AE风味动效设计编辑器 15% |
| 游戏设计与开发 | 15% | 动态路由塔防 15% |
| 物理建模与仿真 | 15% | 物理仿真连锁机关 15% |
| 视觉设计与渲染 | 20% | NVIDIA_B200网页艺术 10%，太阳雨渔港3D渲染 10% |
