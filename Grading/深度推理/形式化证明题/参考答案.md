## 第 1 题

**题目**：设 $a<b$，函数 $q\colon\mathbb{R}\to\mathbb{R}$ 在 $[a,b]$ 上连续，$u\colon\mathbb{R}\to\mathbb{R}$ 二阶连续可微，在 $(a,b)$ 上满足 $u''(x)+q(x)u(x)=0$，$u(a)=u(b)=0$，且 $u$ 在 $(a,b)$ 上不恒为零。证明：$(b-a)\int_a^b|q(x)|\,\mathrm{d}x>4$。

```lean
theorem problem1 (q u : ℝ → ℝ) (a b : ℝ) (hab : a < b)
    (hq : ContinuousOn q (Set.Icc a b)) (hu : ContDiff ℝ 2 u)
    (hode : ∀ x ∈ Set.Ioo a b, deriv (deriv u) x + q x * u x = 0)
    (ha : u a = 0) (hb : u b = 0) (hne : ∃ x ∈ Set.Ioo a b, u x ≠ 0) :
    4 < (b - a) * ∫ x in a..b, |q x| := by
  sorry
```

**证明思路**

- 取 $u^2$ 在 $[a,b]$ 上的最大值点 $c$，记 $M=|u(c)|>0$。由 $u(a)=u(b)=0$ 得 $a<c<b$，于是 $u'(c)=0$。
- 在 $[a,c]$ 上：由 $u'(c)=0$，对 $x\in[a,c]$ 有 $|u'(x)|=\bigl|\int_x^cu''\bigr|\le\int_a^c|u''|\le M\int_a^c|q|=:K$。于是 $M=\bigl|\int_a^cu'\bigr|<(c-a)K$；不等号是严格的：$u(c)\ne u(a)$，所以 $u'$ 在 $[a,c]$ 上不恒为零，$K>0$；而连续函数 $|u'|$ 处处不超过 $K$，在 $c$ 处取值 $0<K$。得 $\int_a^c|q|>\frac1{c-a}$。同理 $\int_c^b|q|>\frac1{b-c}$。
- 两式相加，再用 $\frac1{c-a}+\frac1{b-c}=\frac{b-a}{(c-a)(b-c)}\ge\frac4{b-a}$，得 $(b-a)\int_a^b|q|>4$。

完整的 Lean 参考证明：`参考证明\Problem1.lean`。

## 第 2 题

**题目**：设 $p$ 是奇素数，$\mathbb{F}_p$ 是 $p$ 元域，函数 $f\colon\mathbb{F}_p\to\mathbb{F}_p$ 不能写成 $f(x)=ax+b$（$a,b\in\mathbb{F}_p$）的形式。对 $m\in\mathbb{F}_p$，若存在 $x\ne y$ 使 $f(x)-f(y)=m(x-y)$，就称 $m$ 是 $f$ 的图像确定的一个方向。证明：这样的方向至少有 $\dfrac{p+3}{2}$ 个。

```lean
theorem problem2 (p : ℕ) [Fact p.Prime] (hp : 2 < p)
    (f : ZMod p → ZMod p)
    (hf : ¬ ∃ a b : ZMod p, ∀ x, f x = a * x + b) :
    p + 3 ≤ 2 * Set.ncard {m : ZMod p |
      ∃ x y : ZMod p, x ≠ y ∧ f x - f y = m * (x - y)} := by
  sorry
```

**证明思路**

- 记方向集为 $D$，$N=|D|$。若 $m\notin D$，则 $x\mapsto f(x)-mx$ 是 $\mathbb{F}_p$ 上的双射，所以对 $1\le k<p-1$ 有 $\sum_x(f(x)-mx)^k=\sum_yy^k=0$。
- 令 $M_k(t)=\sum_x(tx+f(x))^k=\sum_{j\le k}\binom kj\Bigl(\sum_xx^jf(x)^{k-j}\Bigr)t^j$。当 $k<p-1$ 时 $t^k$ 的系数 $\sum_xx^k=0$，所以 $\deg M_k\le k-1$；而 $M_k$ 在 $t=-m$（$m\notin D$）这 $p-N$ 个点处为零。因此只要 $M_k\ne0$，就有 $p-N\le k-1$。
- 找一个小的 $k$ 使 $M_k\ne0$：设 $P$ 是 $f$ 的插值多项式，$d=\deg P$，由 $f$ 不是一次函数得 $2\le d\le p-1$。作带余除法 $p-1=a+bd$（$0\le a<d$，$b\ge1$），利用 $p-1$ 为偶数可验证 $2(a+b)\le p-1$。$x^aP(x)^b$ 的次数恰为 $p-1$，而 $\sum_xx^j=0$（$j<p-1$）、$\sum_xx^{p-1}=-1$，所以 $\sum_xx^af(x)^b$ 等于其首项系数的相反数，不为零；又 $a+b<p$，$\binom{a+b}{a}\not\equiv0\pmod p$。故 $M_{a+b}$ 的 $t^a$ 系数非零。
- 取 $k=a+b\le\frac{p-1}2$，得 $p-N\le\frac{p-3}2$，即 $N\ge\frac{p+3}2$。

完整的 Lean 参考证明：`参考证明\Problem2.lean`。

## 第 3 题

**题目**：设 $\mathcal A$ 是由有限集组成的非空有限集族，并且对并运算封闭（$a,b\in\mathcal A$ 时 $a\cup b\in\mathcal A$）。证明：$|\mathcal A|^{|\mathcal A|}\le 2^{2\sum_{a\in\mathcal A}|a|}$，也就是 $\mathcal A$ 中集合的平均大小至少为 $\frac12\log_2|\mathcal A|$。

```lean
theorem problem3 {α : Type*} [DecidableEq α]
    (A : Finset (Finset α)) (hA : A.Nonempty)
    (hunion : ∀ a ∈ A, ∀ b ∈ A, a ∪ b ∈ A) :
    A.card ^ A.card ≤ 2 ^ (2 * ∑ a ∈ A, a.card) := by
  sorry
```

**证明思路**（Reimer 的证明）

- 记 $m=|\mathcal A|$，$u$ 为全部成员之并，$n=|u|$。对每个 $a\in\mathcal A$，在满足“$a\subseteq s\subseteq u$，且 $\mathcal A$ 中含于 $s$ 的成员都含于 $a$”的集合 $s$ 中取 colex 序最大的一个，记为 $f(a)$。区间 $[a,f(a)]=\{t:a\subseteq t\subseteq f(a)\}$ 两两不交，所以 $\sum_a2^{d_a}\le2^n$，其中 $d_a=|f(a)|-|a|$。
- 利用并封闭性和 colex 极大性可证：$f$ 是单射，且 $\mathcal U=\{f(a)\}$ 是 $u$ 的子集格中的上集（对 $x\in u$，$f(a)\cup\{x\}$ 仍是某个 $f(c)$）。于是补集族 $\{u\setminus f(a)\}$ 是下集。
- 下集 $\mathcal D$ 满足 $\sum_{s\in\mathcal D}|s|\le\frac12|\mathcal D|\log_2|\mathcal D|$：按某个元素把 $\mathcal D$ 分成不含它的部分和含它的部分（后者去掉该元素后含于前者），对 $|\mathcal D|$ 归纳，归纳步就是二元熵函数的不等式 $H(p)\ge2p$（$0\le p\le\frac12$）。由此 $\sum_a(n-|f(a)|)\le\frac m2\log_2m$。
- 由 $\sum_a2^{d_a}\le2^n$ 和 $\ln x\le x-1$（取 $x=m2^{d_a}/2^n$ 后求和）得 $\sum_ad_a\le mn-m\log_2m$。
- 三部分相加：$\sum_a\bigl(d_a+(n-|f(a)|)+|a|\bigr)=mn$，所以 $\sum_a|a|\ge m\log_2m-\frac m2\log_2m=\frac m2\log_2m$，即 $m^m\le2^{2\sum_a|a|}$。

完整的 Lean 参考证明：`参考证明\Problem3.lean`。

## 第 4 题

**题目**：设自然数 $r\le n$，$S$ 是 $n$ 阶复矩阵空间的复线性子空间，其中每个矩阵的秩都不超过 $r$。把 $n$ 阶复矩阵 $A$ 看成 $\mathbb{C}^n$ 上的线性映射 $x\mapsto Ax$。证明：$\dim S\le nr$；并且当 $\dim S=nr$ 时，或者存在 $\mathbb{C}^n$ 的 $r$ 维子空间 $U$，包含 $S$ 中所有矩阵的像，或者存在 $\mathbb{C}^n$ 的 $n-r$ 维子空间 $W$，含于 $S$ 中所有矩阵的核。

```lean
theorem problem4 (n r : ℕ) (hr : r ≤ n)
    (S : Submodule ℂ (Matrix (Fin n) (Fin n) ℂ))
    (hS : ∀ A ∈ S, A.rank ≤ r) :
    Module.finrank ℂ S ≤ n * r ∧ (Module.finrank ℂ S = n * r →
      (∃ U : Submodule ℂ (Fin n → ℂ), Module.finrank ℂ U = r ∧
        ∀ A ∈ S, LinearMap.range A.mulVecLin ≤ U) ∨
      (∃ W : Submodule ℂ (Fin n → ℂ), Module.finrank ℂ W = n - r ∧
        ∀ A ∈ S, W ≤ LinearMap.ker A.mulVecLin)) := by
  sorry
```

**证明思路**

- 取 $S$ 中秩最大的矩阵 $M$，秩为 $\rho\le r$。用可逆矩阵 $P,Q$ 把 $S$ 换成 $PSQ$（维数、秩不变，像和核随之变换），可设 $M=\mathrm{diag}(I_\rho,0)$。
- 对 $A=\begin{pmatrix}A_{11}&A_{12}\\A_{21}&A_{22}\end{pmatrix}\in S$，$M+tA$ 的秩对所有 $t$ 都不超过 $\rho$。$t$ 很小时 $I+tA_{11}$ 可逆，Schur 补 $tA_{22}-t^2A_{21}(I+tA_{11})^{-1}A_{12}$ 必须为零，按 $t$ 展开得 $A_{22}=0$，$A_{21}A_{12}=0$，$A_{21}A_{11}A_{12}=0$。
- 维数上界：实线性映射 $A\mapsto(A_{11},\,A_{12}+A_{21}^{*})$ 在 $S$ 上是单射（像为零时 $A_{21}A_{21}^{*}=-A_{21}A_{12}=0$，故 $A_{21}=0$，进而 $A=0$）。比较实维数得 $2\dim S\le2(\rho^2+\rho(n-\rho))$，即 $\dim S\le n\rho\le nr$。
- 等号情形（$n=0$ 平凡）：$\dim S=nr$ 推出 $\rho=r$，且上述映射是满射，于是所有 $\mathrm{diag}(X,0)$ 都在 $S$ 中。对 $A+\mathrm{diag}(X,0)$ 用上一步的关系，得 $A_{21}XA_{12}=0$ 对一切 $X$ 成立，所以每个 $A\in S$ 都有 $A_{12}=0$ 或 $A_{21}=0$；再看两个矩阵之和，可知要么 $S$ 中所有 $A_{12}=0$（所有矩阵的核都含后 $n-r$ 个坐标向量张成的子空间），要么所有 $A_{21}=0$（所有矩阵的像都含于前 $r$ 个坐标向量张成的子空间）。变回原来的坐标即得结论。

完整的 Lean 参考证明：`参考证明\Problem4.lean`。

## 第 5 题

**题目**：记 $\mathbb{D}=\{z\in\mathbb{C}:|z|<1\}$ 为单位开圆盘。设函数 $f\colon\mathbb{C}\to\mathbb{C}$ 在 $\mathbb{D}$ 上全纯（$\mathbb{D}$ 外的取值任意），$f(\mathbb{D})\subseteq\mathbb{D}$，且 $f$ 在 $\mathbb{D}$ 内没有不动点。证明：存在模为 $1$ 的复数 $w$，使得当 $n\to\infty$ 时，$f$ 的 $n$ 次迭代 $f^{\circ n}$ 在 $\mathbb{D}$ 上局部一致收敛到常数 $w$（等价地，在 $\mathbb{D}$ 的每个紧子集上一致收敛到 $w$）。

```lean
theorem problem5 (f : ℂ → ℂ)
    (hf : DifferentiableOn ℂ f (Metric.ball 0 1))
    (hm : Set.MapsTo f (Metric.ball 0 1) (Metric.ball 0 1))
    (hfix : ∀ z ∈ Metric.ball (0 : ℂ) 1, f z ≠ z) :
    ∃ w : ℂ, ‖w‖ = 1 ∧
      TendstoLocallyUniformlyOn (fun n : ℕ => f^[n]) (fun _ => w)
        Filter.atTop (Metric.ball 0 1) := by
  sorry
```

**证明思路**

- Schwarz–Pick 引理：$\mathbb{D}$ 到自身的全纯映射不增大伪双曲距离 $\bigl|\frac{a-z}{1-\bar az}\bigr|$。
- Wolff 引理：取 $r_k\uparrow1$。$r_kf$ 把 $\mathbb{D}$ 映入半径 $r_k$ 的闭圆盘，由 Schwarz–Pick，它在这个闭圆盘上是伪双曲距离下的压缩映射，因而有不动点 $a_k$。因为 $f$ 没有不动点，$|a_k|\to1$；取子列使 $a_k\to w$，$|w|=1$。把 Schwarz–Pick 不等式在 $a=a_k$ 处写成分式形式后取极限，得到对一切 $z\in\mathbb{D}$，
  $\dfrac{|1-\bar wf(z)|^2}{1-|f(z)|^2}\le\dfrac{|1-\bar wz|^2}{1-|z|^2}$，
  即 $f$ 把以 $w$ 为切点的每个极限圆（horodisc）映入自身。记 $C(z)=\frac{1+\bar wz}{1-\bar wz}$，上式等价于 $\operatorname{Re}C(f(z))\ge\operatorname{Re}C(z)$。
- 轨道 $u_n=f^{\circ n}(0)$ 收敛到 $w$：$\operatorname{Re}C(u_n)$ 单调不减。令 $g=C\circ f-C$，则 $\operatorname{Re}g\ge0$。
  - 若 $\operatorname{Re}g$ 在 $\mathbb{D}$ 内某点为 $0$，由开映射定理 $g$ 恒为常数 $c$，且 $c\ne0$（否则 $f$ 有不动点），于是 $C(u_n)=1+nc\to\infty$，$u_n\to w$。
  - 否则 $\operatorname{Re}g>0$。设 $a$ 是 $u_n$ 在闭圆盘中的聚点：若 $|a|<1$，由单调性 $\operatorname{Re}C(u_n)$ 收敛，沿子列取极限得 $\operatorname{Re}g(a)=0$，矛盾；若 $|a|=1$，由 $\operatorname{Re}C(u_n)\ge\operatorname{Re}C(u_0)=1$ 得 $|1-\bar wu_n|^2\le1-|u_n|^2$，取极限得 $a=w$。聚点唯一，故 $u_n\to w$。
- 局部一致收敛：对 $|z|\le r<1$，对 $f^{\circ n}$ 在 $0$ 和 $z$ 两点用 Schwarz–Pick，得 $|f^{\circ n}(0)-f^{\circ n}(z)|\le\frac{r(1-|f^{\circ n}(0)|^2)}{1-r}\to0$，所以 $f^{\circ n}$ 在 $|z|\le r$ 上一致收敛到 $w$。
