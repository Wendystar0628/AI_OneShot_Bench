一道题怎么测

11 道题都走同样的四步；两类题在交付、评分员和计分方式上不同。

1

拿到题面

空的作答目录里只放这道题的题面
目录是一个 git 仓库

2

独立作答

新会话从拿到题面起计时
无人答疑，模型看不到限时

3

到时中止

时间一到立即结束，不延长
可用的阶段由模型自己 git 提交

4

评分与合成

评完整的工作目录或最近的提交
每题折算 0–100，按权重加总

标准评判题6 题
主动设计题5 题
类别
深度推理 算法竞赛
复杂交互应用 游戏设计与开发 物理建模与仿真 视觉设计与渲染
交付
Lean 证明、IMO 解答、极值构造、CUDA 或 C++ 源码
网页作品，双击 index.html 就能运行
限时
60 分钟
100 分钟，物理 120 分钟
评分员
GPT 6.1 Sol 单评
能精确计算的部分由脚本算出
Claude Opus 5.5 与 GPT 6.1 Sol 各评，主体分项取平均
性能分项只由 Sol 评
计分
编译检查、IMO 阅卷、锚点表、加速比
每个分项在分值内直接打分，相加满分 100
权重合计
35%
65%
