五种题型怎样计分

各题型先得出原始分，再折算成 0–100 分。每块最下一行是需要单独说明的情形。

形式化证明题

5 题，每题只有 0 分或 20 分。单独编译没有错误、也没有 sorry 警告才得 20 分。

缺文件：这一题 0 分，不影响其他题

IMO原创新题

12 题，每题 0–7 的整数分，满分 84，再乘以 100/84 折算。

多种做法未注明：按得分最低的一份评

设计题

每题 19–29 个分项，分值合计 100。评分员在每个分项的分值内直接打分，相加为总分。

不分档、不扣分：AE 的性能另按用时公式

极值构造题

以已知最好的构造值为满分基准查锚点表。低段到中高段斜率逐段加大，逼近纪录的最后一段不额外加权。

记 0 分：提交无效，如点数不对、点在正方形外

性能工程题

24 个性能输入各算加速比 s = 基线用时 ÷ 提交用时，在对数尺度上查锚点后取平均，再乘以正确性输入的通过比例 k/7。

记 0 分：编译失败或违反题面规则；单个输入失败只丢这个输入
